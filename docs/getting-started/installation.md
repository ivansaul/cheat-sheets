# Installation

Cheat Sheets is currently available for Android and iOS devices. The installation process differs between platforms.

## Android

You can install the app directly via the Google Play Store or by downloading the APK from GitHub.

=== ":fontawesome-brands-google-play: Google Play Store"

    Install directly from the store: [Google Play][google-play]
    
=== ":fontawesome-brands-github: GitHub Releases"

    Download the latest `.apk` or `.aab` file from the [Releases page][github-releases].

## iOS

On iOS, the app is distributed via **AltStore** (no jailbreak required).

!!! note "Prerequisites"
    You need to have AltStore installed on your device first. Please refer to the official [macOS][altstore-doc-macos] or [Windows][altstore-doc-windows] installation guides, or follow the video tutorials for [macOS][altstore-video-macos] and [Windows][altstore-video-windows].

### Install with AltStore

Once AltStore is installed, you can add Cheat Sheets via our custom source or by manually sideloading the `.ipa` file.

=== ":fontawesome-brands-app-store-ios: AltStore Source"

    Add our source to your AltStore application: [AltStore Source][altstore-source]

=== ":fontawesome-brands-apple: Manual Installation"

    Download the `.ipa` file from [GitHub Releases][github-releases] and open it with AltStore. This is the **recommended** approach.

!!! bug "Launch Warning"
    Opening the app via the **OPEN** button inside AltStore may cause deeplink issues. Please launch the application from your **home screen icon** instead. This will be addressed in a future update.
